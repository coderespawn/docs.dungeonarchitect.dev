---
title: "Pattern Matcher"
sidebar_position: 1
---

Capture patterns in your dungeon layout and add or remove markers around this pattern. 
This is a powerful system for decorating your themes, as you are no longer restricted to a single tile level decoration
and can decorate across multiple tiles using your own patterns

# Snap Flow Builder

This system lets you stitch together pre-built rooms based on a procedural graph.

![ut-05-snap-dungeon-overview.jpg](ut-05-snap-dungeon-overview.jpg)

These graphs are generated using Graph Grammar rules, an intuitive and powerful way of designing your dungeon layouts.

![ut-05-snap-graph-overview.jpg](ut-05-snap-graph-overview.jpg)

It gives you complete control on the layout and opportunities to rewrite and grow the graph as needed

![ut-05-snap-editor-overview.jpg](ut-05-snap-editor-overview.jpg)
